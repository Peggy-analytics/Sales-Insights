# vehicle sales performance
## Project Overveiw
This project analyzes vehicle sales data to identify sales trends, customer preferences,and business performance across different regions.
## Objectives
- Analyze sales performances by region
- Identify top-selling vehicle models
- compare fuel tyoes and transmission preferences
- Track yearly sales trends
## Tools used
- Excel
- Pivot tables
- Datat cleaning
## Dashboard Features 
- Regional sales analysis
- Sales trend visualization
- Fuel type comparison
- Transmission analysis
- KPI summary cards
## Key Insights
- SUVs had the highest sales volume 
- Automatic transmission vehicles generated more revenue
- Sales increased significantly in the south region
- Hybrid vehicles showed growing customer interest
